# Umiya — Exclusive Car Rental

Premium multi-page frontend website for Umiya Exclusive Car Rental & Travel Services.

## Run

```bash
npm install
npm run dev
```

## Pages

- `/` Home
- `/about` About
- `/cars` Cars
- `/services` Services
- `/destinations` Destinations
- `/gallery` Gallery
- `/contact` Contact + FAQ
